# Facebook — usage notes for the planner

- Search icon: located in the top bar, icon-only magnifier with no text label; use vision coordinates when the node tree has no match.
- Screen after tapping search: search field appears at the top, and the soft keyboard opens.
- Typing in search: typing needs the field focused first (tap field, wait for keyboard to appear, set text via ACTION_SET_TEXT, read back to verify, then press Enter).
- News Feed: posts in a vertical list; feed scrolls are normal and expected; repeated scrolls are not a loop failure.
- Bottom navigation: Home, Friends, Video, Marketplace, Notifications, Menu.
- To open a specific page or person, search for the name — do not scroll the feed hoping it appears.
- Videos play inline in the feed; tap a video to open it full-screen.
